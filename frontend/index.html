GreenPulse is an automated carbon-aware orchestration engine for high-compute AI workloads. Instead of running tasks the moment they're submitted, it reads live power grid data, compute resource specs, and operational constraints to decide when and where each job should run — cutting emissions without ever missing a deadline.
