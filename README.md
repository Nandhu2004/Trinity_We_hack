# GreenPulse

## What If AI Knew When Not to Run?

**Carbon-Aware & Resilience-Aware AI Orchestration**

GreenPulse is an intelligent AI workload orchestration system that determines **where and when AI workloads should run** based on carbon intensity, renewable energy availability, grid conditions, workload priority, and latency.

Instead of blindly routing workloads to the nearest available server, GreenPulse selects a **cleaner and more resilient execution option** while maintaining performance.

## Features

- Carbon-aware workload routing
- Renewable energy awareness
- Grid-resilience-aware scheduling
- Flexible workload delay and scheduling
- Workload priority-based decisions
- Carbon impact monitoring
